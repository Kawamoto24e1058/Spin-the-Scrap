# ゲーム設計（2026-10-21 改訂）

要件書（2026-10-20 版）の「借金を返すために潜る」ループは、物理で物を運んで脱出地点から売る協力ホラー（R.E.P.O. など）と、
スロット型のデッキ構築（Luck be a Landlord など）の骨組みをそのまま重ねた形になっていた。
既視感を外すため、**戦って階層を下る協力アクション**にし、スロットは **強くなるための手段** に絞る。

一言でいうと：**ガラクタで回して、ありえないほど強くなって、ボスをぶっ飛ばす。**

## 残すもの・なくすもの

- 残す：拾ったガラクタがリールになる（作品の売り）、協力プレイ、物理で運ぶ手触り、自動生成の施設、敵・ハザード・音
- なくす：借金、返済日、ノルマ、店での即売、脱出地点
- スロットはゲーム内通貨（メダル）だけで回す。現実のお金・ガチャ・ルートボックスは入れない

## 1 ランの流れ

- 地下へ 9 階層（ボス 3 体）。**通常 → 通常 → ボス** の繰り返し。目安 45〜60 分。
- 通常の階：自動生成の施設。敵を指定の数だけ倒すとエレベーターが動く。
- ボス階層：決まった形の階層。手前の安全部屋に改造スロット、奥にもう 1 台。ボスを倒すと次へ。
- 残機 3。倒れると換金前のガラクタを失い、その階層をやり直す。0 でラン終了。
- 長居するほど危ない：時間がたつと敵が湧き直し、だんだん強くなる。

## スロット台（4 種類）

台は階層のあちこちに置く（通常の階に 2〜3 台）。**回すと大きな音が鳴り、敵が寄ってくる。**

| 台 | 出る物 | 費用（階層 1 の 1 回目） |
| --- | --- | --- |
| 武器スロット | 武器そのもの | 6 |
| 強化スロット | 自分の能力（タグのレベル） | 4 |
| 改造スロット | 持っている武器に改造を付ける（ボス階層の手前など限られた場所） | 8 |
| 道具スロット | 包帯・爆竹・電池などの消耗品 | 2 |

- **台の種類ごとにリールが別**。リールはランを通して持ち越す（どの階の武器スロットも同じ武器リール）。
- 拾ったガラクタは台に入れて、「メダルに換える」か「その台のリールに入れる」かを選ぶ。
  何を入れたかで、その台から何が出やすいかを自分たちで組み立てられる（ランダムな武器箱との一番の違い）。
- 費用は階層が深いほど ×1.2、同じ台の種類を同じ階で回すほど ×1.3。換金のメダルも深いほど +20%／階。どの階層でも 1 種類の台を 7〜9 回回せるくらい。
- 回した結果の決め方（共通）：盤面のシンボルの最終的な値（隣接効果・倍率・ラインを全部かけた後）を、そのシンボルのタグごとに合計する。
  - **系統** ＝ 合計がいちばん大きいタグ
  - **質（1〜3）** ＝ 盤面の合計の値（20 未満 → 1、45 未満 → 2、それ以上 → 3）。幸運を含むラインがあると +1（上限 3）
  - 隣接効果やラインで値を伸ばすほど、良い物が出る

### 武器スロット：系統 → 武器

| 系統 | 質 1 | 質 2 | 質 3 |
| --- | --- | --- | --- |
| 金属 | 鉄パイプ（近接） | 釘打ち機（連射） | リベット砲（貫通） |
| 電化製品 | スタンガン（近接・ひるみ） | 放電銃（連鎖） | 放電銃（連鎖・強） |
| おもちゃ・人形 | 爆竹（投げる） | 花火筒（爆発） | 花火筒（爆発・強） |
| 呪い | 呪いの包丁（近接・大ダメージ、使うと少し傷つく） | 同・強 | 同・最強 |
| その他 | 鉄パイプ | 釘打ち機 | 釘打ち機 |

### 強化スロット：タグの経験値 → レベル

回すたびに、タグごとの合計の値がそのタグの経験値になる。経験値 20 / 60 / 140 / 260 / 440 で Lv1〜5（空き缶だけなら 1 回 5 前後、組み合わせを作ると 20〜40）。

| タグ | 効果（Lv ごと） |
| --- | --- |
| 金属 | 攻撃力 +15% |
| 電化製品 | 攻撃が 8% でひるませる |
| 食べ物 | 最大体力 +15、Lv3 から倒すたびに 5 回復 |
| 幸運 | 会心率 +6%（会心は 2 倍） |
| 割れ物 | 移動速度 +5% |
| おもちゃ | 爆発の範囲 +15% |
| 呪い | 攻撃力 +30%、被ダメージ +10% |
| ギャンブル | 換金のレート +10% |
| 紙 | 8m 以内の敵の位置が壁越しに見える（Lv ごとに +8m） |
| 人形 | 敵に見つかる距離 -8%（上限 -60%） |

- 強化はレバーを引いた人に入る。協力プレイでは「誰に回させるか」が相談になる。

### 改造スロット：系統 → 武器の改造（1 本に 3 つまで）

| 系統 | 改造 |
| --- | --- |
| 金属 | 攻撃力 +30% |
| 電化製品 | 当てるとひるむ |
| 食べ物 | 与えたダメージの 10% 回復 |
| 割れ物 | 攻撃の間隔 -20% |
| 紙 | 弾数・耐久 +50% |
| 呪い | 攻撃力 +60%、当てるたびに自分に 2 ダメージ |
| その他 | 攻撃力 +15% |

### 道具スロット：系統 → 消耗品（数は質に比例）

食べ物 → 包帯、おもちゃ・人形 → 爆竹、電化製品 → 電池、その他 → メダル

## 大当たり

盤面の合計の値が 100 以上のときは大当たり。全員に強化スロット 1 回分の経験値が入るが、とても大きな音（半径 40m）が鳴る。

## 敵

| 敵 | 体力（階層 1） | 特徴 |
| --- | --- | --- |
| 這う者（雑魚） | 40 | 群れで来る。倒すとガラクタを落とすことがある |
| 徘徊者 | 150 | 音と光に寄ってくる。正面から倒すよりひるませて逃げる相手 |
| ボス：目の見えない巨体 | 900 | 音だけを頼りに突進する。爆竹でおびき寄せ、壁にぶつけた隙に叩く |
| ボス：電気を吸う機械（地下 6 階） | 1400 | 電気の武器か、ひるんでいるときしかまともに効かない（ほかは 30%）。5 秒ごとに光ってから周りへ放電（7m・物陰でよけられる） |
| ボス：群れを呼ぶ人形（地下 9 階） | 700 | 距離をとって 6 秒ごとに這う者を呼ぶ（6 体まで）。爆発に弱い（1.5 倍） |

体力は階層ごとに ×1.25、攻撃は ×1.15。

## 協力プレイ

ホスト権威型（FishNet、今はローカルネットワークの Tugboat）。始める前の画面で「ひとり・ホスト・参加（IP アドレス）」を選ぶ。

| 物 | 決める人 | 配り方 |
| --- | --- | --- |
| 間取り・スロット台・水たまり | 全員が同じシードから組み立てる | NetSession（ランのシード・階層・やり直し回数） |
| ランの状態（メダル・リール・強化・武器・道具・台に入れたガラクタ・攻略条件） | ホスト | NetSession が RunSession.SaveState の文字列を配り、クライアントは写す |
| 敵 | ホスト | NetEnemy（位置・体力・ひるみ）。クライアントの攻撃は NetPlayer からホストへ |
| ガラクタ | 拾った人（誰も持っていなければホスト） | NetScrap（NetworkTransform は持ち主の権威）。しまった物はほかの人にも見えない |
| 自分の分身・体力・武器の耐久 | その人 | NetPlayer |

- クライアントがスロット台を操作すると（台に入れる・換金・リールに入れる・回す・廃棄・レリック）、NetPlayer がホストへ送り、ホストの RunSession が行う。
- 回したとき、ホストは「回す直前の状態」をその人に返し、クライアントは同じ状態から同じ乱数で回し直して結果を見せる（結果を別に送らなくてよい）。
- 協力プレイで倒れたら、仲間がそばで [R] を 2.5 秒押し続けると体力 30% で起き上がる（残機は減らない）。[F] で引きずって安全な所へ運べる。待たずに「あきらめる」と入口で起き上がり、残機が 1 減る（残機は全員で共有）。
- 特大はホストが物理を計算し、持っている人それぞれの「引っ張る力」（上限あり）を足す。1 人では持ち上がらず引きずるだけ、2 人なら持ち上がる。
- ほかの人が台を回すと、自分の画面でもその台のリールが回る（ホストが「回す直前の状態」と台の番号を全員に配り、各自が同じ乱数で回し直して見せる）。
- まだ：台車はホストにしかない。クライアントが投げたガラクタは敵に当たらない。倒した人の回復（食べ物の強化）はホストだけ。

## あとでやること

- 武器のモーションの作り込み（今はプリミティブの武器を、コードで振る・反動・揺れを付けているだけ）
- 数値の調整（武器の強さ、敵の体力、費用、倒す数）

## 作る順番（試作）

1. Core：台の種類とリール、結果の決め方（武器・強化・改造・道具）、プレイヤーの能力値、敵の強さ、階層の並び（テスト付き）
2. 戦闘：武器の振る・撃つ、敵の体力とダメージ、雑魚「這う者」
3. 台を施設に置く（武器・強化・道具）、ガラクタを入れる流れ、回すと音
4. ボス階層：決まった形の階層、改造スロット、目の見えない巨体
5. 古い仕組み（脱出地点など）を消し、README・docs を更新
