# 階層攻略への方向転換（2026-10-21）

要件書（2026-10-20 版）の「借金を返すために潜る」ループは、物理で物を運んで脱出地点から売る協力ホラー（R.E.P.O. など）と、
スロット型のデッキ構築（Luck be a Landlord など）の骨組みをそのまま重ねた形になっていた。
既視感を外すため、潜る側の目的を「運び出して売る」から「階層を攻略して下る」に変える。

残すもの：

- **拾ったガラクタがリールになる**（作品の売り）
- 協力プレイ、物理で運ぶ手触り、自動生成の施設、敵・ハザード・音
- スロットはゲーム内通貨（メダル）だけで回す。現実のお金・ガチャ・ルートボックスは入れない

なくすもの：借金、返済日、ノルマ、店での即売。

## ランの流れ

1. ランは地下へ下る全 10 階層。階層ごとに施設を自動生成し、攻略条件を 1 つ選ぶ。
2. スタート地点に **ガラクタ・スロット台** と **エレベーター** がある。
3. 探索してガラクタを集め、スロット台に入れる。入れた物は次のどちらかにする。
   - **リールに入れる**：シンボルになる。リールはランを通して持ち越す。
   - **メダルに換える**：回す費用になる。
4. メダルで回すと、当たったラインのタグに応じた **出る物**（武器・道具）が台から出る。ラインが長いほど良い物。
5. 攻略条件を満たすとエレベーターが動き、次の階層へ。倒れたら、その階層の持ち物を落として最初の部屋からやり直す（ランの失敗条件は別途調整）。

## 攻略条件（階層ごとにランダム）

| 種類 | 内容 |
| --- | --- |
| 鍵を探す | 施設のどこかにある鍵を見つけ、エレベーターまで持ち帰る |
| 敵を倒す | 指定の数だけ敵を倒す |
| 発電機を動かす | 発電機にガラクタを入れ、指定の電力（ガラクタの価値の合計）をためる |
| 特大を運ぶ | 指定の特大のガラクタをエレベーターまで運ぶ |

## スロットから出る物（タグ → 出る物）

| タグ | 出る物の例 |
| --- | --- |
| 金属 | 鉄パイプ（近接・耐久あり）、釘打ち機（遠距離・弾数あり） |
| 電化製品 | スタンガン（ひるませる）、電池 |
| 食べ物 | 回復 |
| おもちゃ | 爆竹・おとり |
| 呪い | 強いが代償のある道具 |
| 幸運 | 出る物の質を 1 段上げる |
| その他 | メダル |

## 戦闘

- 戦うことも逃げることもできる。武器は耐久や弾数に限りがあり、強い敵からは隠れる・おびき寄せる・逃げる選択も要る。
- 今の「音・懐中電灯に寄ってくる」敵の仕組みはそのまま生かす。
- 敵は体力を持つ。徘徊者（強い）に加えて、弱いが群れる敵を足す。
